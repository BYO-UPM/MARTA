# MARTA: a model for the automatic phonemic grouping of the parkinsonian speech


![Logo](logo1.png)


This repository contains Python scripts implementing the Manner of ARTiculation Analysis (MARTA) based on a Gaussian Mixture Variational Autoencoder (GMVAE) model. MARTA is designed for speech feature analysis, focusing on manner class articulation in Parkinson's Disease (PD) research. This repository includes various scripts for different aspects of analysis, from unsupervised clustering to supervised training emphasizing latent space organization and discrimination.

## Code versions and tags
### Tag 1.0.0: MARTA
For the code associated with the original MARTA model, refer to the 1.0.0 tag. This version analyzes manner class articulations of healthy speech and evaluates latent space cluster distances across datasets such as Albayzin and NeuroVoz. For more details, see the [MARTA paper.](https://www.techrxiv.org/doi/full/10.36227/techrxiv.171084943.31044695)

Guerrero-López, A., Arias-Londoño, J. D., Shattuck-Hufnagel, S., & Godino-Llorente, J. I. (2024). MARTA: a model for the automatic phonemic grouping of the parkinsonian speech. Authorea Preprints.


### Tag 2.0.0: MARTA-DOS
This version introduces MARTA-DOS, which includes domain-adversarial training and integrates multiple Spanish datasets (NeuroVoz, Albayzin, and GITA). The code for this model can be found under the 2.0.0 tag.

A preprint will come soon.

### Tag 3.0.0: MARTA Multilingual
This version extends MARTA-DOS with multilingual domain-adversarial training, incorporating Albayzin and LibriSpeech as normophonic datasets and using NeuroVoz and GITA for downstream Parkinsonian classification tasks. The code for this model is tagged as 3.0.0.

Currently on going. The tag will be available soon.

## Updated Key Scripts
1. **marta_supervised_multilingual.py**
Trains the multilingual MARTA latent space, projecting each spectrogram window into a region of the latent space based on the manner class detected (for testing) or labeled (for training).

2. **marta_supervised.py**
Trains the multi-dataset Spanish MARTA latent space, performing the same operations as the multilingual script but focusing on Spanish datasets (NeuroVoz, Albayzin, and GITA).

3. **marta_S_classifier.py**
Trains a classifier on Parkinsonian condition using a pre-trained latent space (either multilingual or multi-dataset Spanish). The classifier uses a CNN to provide predictions for each spectrogram, followed by a joint probability consensus to classify the overall condition of a patient based on multiple audio samples (if available).

## Installation

To set up the project using Conda, follow these steps:

```bash
# Clone the repository
git clone https://github.com/BYO-UPM/MARTA.git
cd MARTA

# Create a Conda environment from the .yml file
conda env create -f environment.yml

# Activate the Conda environment
conda activate your-env-name
```

## Usage

Each script can be run independently, depending on the specific analysis you wish to perform. Here are the general steps to follow:

1. **Prepare Your Data:** Ensure your speech data is correctly formatted and stored in the required directories.
2. **Configure Hyperparameters:** Adjust the hyperparameters in each script according to your data and analysis needs.
3. **Run the Script:** Execute the script using a Python interpreter. For example:

   ```bash
   python marta_supervised_multilingual.py --fold 0 --gpu 1
   python marta_supervised.py --fold 0 --gpu 1
   python marta_S_classifier.py --fold 0 --gpu 1
   ```

4. **Analyze Results:** Check the output files and visualizations generated by the scripts for analysis.

Detailed usage for each script is documented within the script files themselves.

In __scripts__ folder you can find different bash scripts to run configurations of these models.
